🧭 Zed 编辑器 macOS 快捷键速查（中文说明） ​

🗂️ 工作区与文件操作 ​

快捷键功能
⌘ + P模糊搜索并打开文件
⌘ + Shift + P打开命令面板（可执行所有命令）
⌘ + Shift + E打开项目（选择文件夹）
⌘ + Shift + N新建 Zed 窗口
⌘ + W关闭当前标签页或面板
⌘ + Shift + T重新打开上一个关闭的文件
⌘ + ,打开设置（Preferences）
⌘ + K ⌘ + S打开键盘映射编辑器（修改快捷键）

🧭 侧边栏与导航 ​

快捷键功能
⌘ + \显示 / 隐藏文件树（Project Sidebar）
⌃ + 0聚焦文件树
⌘ + 1 或 Esc聚焦编辑器
⌘ + Shift + [ / ⌘ + Shift + ]切换上一个 / 下一个标签页
⌘ + Option + ← / →切换编辑器分栏焦点
⌘ + Option + ↑ / ↓上下分屏切换焦点
⌘ + K ⌘ + ← / ⌘ + K ⌘ + →移动文件树与编辑器焦点切换

🧑‍💻 编辑操作 ​

快捷键功能
⌘ + /切换行注释
⌘ + D选中下一个相同的单词（多光标选择）
⌘ + U撤销上一个多光标选择
⌘ + Shift + L选中所有匹配项
⌥ + Shift + ↑ / ↓复制当前行向上 / 向下
⌘ + Shift + K删除当前行
⌘ + Enter在下一行插入新行
⌘ + Shift + Enter在上一行插入新行
⌥ + ↑ / ↓移动当前行或选中代码块
⌘ + [ / ⌘ + ]减少 / 增加缩进
⌘ + A全选
⌘ + Z / ⌘ + Shift + Z撤销 / 重做

🔍 查找与替换 ​

快捷键功能
⌘ + F查找当前文件
⌘ + G / ⌘ + Shift + G查找下一个 / 上一个匹配
⌘ + Option + F查找并替换
⌘ + Shift + F全局搜索（整个项目）
⌘ + Enter执行替换

🪄 格式化与代码操作 ​

快捷键功能
⌥ + Shift + F格式化当前文档
⌘ + .显示快速修复（Quick Fix）提示
⌘ + K ⌘ + F格式化所选区域
⌘ + Shift + O跳转到符号（函数 / 类 / 方法）
⌘ + R重新加载文件
⌘ + K ⌘ + R运行当前脚本（需配置任务）

🧩 多光标与列编辑 ​

快捷键功能
⌥ + 点击鼠标添加光标
⌘ + 点击鼠标多光标选择
⌥ + Shift + 拖拽鼠标进入列（块）编辑模式
⌘ + Option + ↑ / ↓添加上 / 下光标
Esc退出多光标模式

🌈 窗口与分屏管理 ​

快捷键功能
⌘ + \切换侧边栏显示
⌘ + K ⌘ + →将编辑器焦点移到右侧分屏
⌘ + K ⌘ + ↑将编辑器焦点移到上方分屏
⌘ + \（重复）创建垂直分屏
⌘ + Option + 2创建左右两分屏
⌘ + Option + 3创建三分屏
⌘ + Option + 1单屏模式

🧠 调试 / 终端 / 运行 ​

快捷键功能
`⌘ + ``打开 / 关闭内置终端
⌘ + K ⌘ + T打开终端新标签
`⌘ + Shift + ``在终端标签间切换
⌘ + K ⌘ + C清空终端输出
⌘ + K ⌘ + X关闭当前终端会话

🧰 其他常用命令 ​

快捷键功能
⌘ + Shift + H显示命令历史
⌘ + Shift + P打开命令面板
⌘ + Q退出 Zed
⌘ + Shift + Q关闭所有窗口并退出
⌘ + Shift + S另存为
⌘ + Shift + .显示隐藏文件

⚙️ 自定义快捷键路径 ​

在命令面板中输入：Open Keymap
配置文件路径：~/Library/Application Support/Zed/keymap.json

示例：

json
[
  { "keys": ["cmd+k", "cmd+f"], "command": "editor.formatDocument" },
  { "keys": ["cmd+b"], "command": "workspace.toggleProjectPanel" }
]
