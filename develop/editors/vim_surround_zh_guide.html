surround.vim 中文手册 ​

surround.vim 是 Vim 的一款极其实用的插件，用于操作各种“包围符号”，如括号、引号、HTML/XML 标签等。

它允许你用极快的方式来添加、修改或删除这些包围内容，极大提升了编写和编辑文本、代码、标记语言的效率。

✨ 插件亮点 ​

  • 快速添加成对符号，如 ()、""、<p></p> 等。
  • 一键替换原有包围为新包围。
  • 支持可视模式操作。
  • 特别适合 HTML/XML 标签处理。

📦 安装方式 ​

Vim 8+ 原生安装 ​

bash
mkdir -p ~/.vim/pack/tpope/start
cd ~/.vim/pack/tpope/start
git clone https://tpope.io/vim/surround.git
vim -u NONE -c "helptags surround/doc" -c q

vim-plug: ​

vim

然后执行 :source ~/.vimrc 和 :PlugInstall 或相应命令。

🔧 快捷键说明 ​

添加包围（add surround） ​

vim
ysiw"       "word"             用双引号包围当前单词
ysiw<q>     <q>word</q>       用 HTML 标签包围
yss)        (line)            用圆括号包裹整行
1
2
3

语法：ys<motion><char> 或 yss<char>

删除包围（delete surround） ​

vim
ds"         word               删除双引号包围
ds<p>       content            删除 HTML 标签
ds)         line               删除圆括号
1
2
3

语法：ds<char>

替换包围（change surround） ​

vim
cs"'        'word'             替换双引号为单引号
cs'<q>      <q>word</q>        替换为 HTML 标签
cs(<{       { word }           括号变花括号并加空格
1
2
3

语法：cs<old><new>

可视模式使用（Visual Mode） ​

在选中模式中按：

vim
S"          "选中内容"          包围选中区域
S<p>        <p>选中</p>         使用 HTML 标签包围
1
2

🧠 motion 参数说明 ​

  • iw 当前单词
  • aw 一个单词含空格
  • i" 包含引号内部
  • a) 一个括号含本体
  • V 行模式

🧾 包围符一览 ​

输入字符包围形式说明
""text"双引号
''text'单引号
) / b(text)圆括号
][text]方括号
} / B花括号（含空格）
>HTML 标签
t提示输入 HTML 标签

💬 示例操作演示 ​

初始文本：

text
Hello world!
1

  1. 把 "Hello" 包进 []：

    vim
    ysiw]
→ [Hello] world!
    1
    2

  2. 替换为花括号并加空格：

    vim
    cs]{
→ { Hello } world!
    1
    2

  3. 删除花括号：

    vim
    ds{
→ Hello world!
    1
    2

  4. 整行包进 HTML 标签：

    vim
    yss<p class="info">
→ <p class="info">Hello world!</p>

❓ 常见问题 ​

为什么括号会加空格？ ​

  • 输入 B 或 { 默认行为会在 {} 中添加空格：{ content }
  • 如不希望加空格，可使用 } 替代 B：{content}

🖥 在 IntelliJ IDEA 中使用 surround（IdeaVim） ​

是否支持 surround ​

IdeaVim 本身不内置 surround 功能，但IdeaVim 插件支持安装插件。

安装方法 ​

  1. 打开 IntelliJ IDEA 设置：Preferences / Settings

  2. 导航至 Plugins

  3. 搜索 IdeaVim

  4. 在 .ideavimrc进行配置安装:

    vim
    set surround                 " 启用 vim-surround 插件，用于操作成对的字符
    1

  5. 重新加载IdeaVim配置即可

支持的命令 ​

插件安装后，大部分经典命令都可使用：

  • ds" 删除包围
  • cs"' 替换包围
  • ysiw) 添加括号

示例 ​

  • 在 IDEA 中打开 .html 文件，将光标移到 <p> 标签内文字上，按 cs<p><span>：将 <p> 替换为 <span>。
