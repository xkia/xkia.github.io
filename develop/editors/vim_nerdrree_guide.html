Vim + NERDTree 常用操作手册 ​

📂 文件浏览 - NERDTree ​

功能快捷键
打开 NERDTree:NERDTreeToggle
打开目录树（当前文件所在目录）:NERDTreeFind
光标移动到目录树Ctrl + w h（或方向键）
打开文件（水平分屏）i
打开文件（垂直分屏）s
打开文件（新 tab）t
打开文件（替换当前窗口）o
关闭目录节点x
打开目录节点o / Enter
返回上级目录u
刷新目录树R
隐藏/显示隐藏文件I

📑 多文件编辑 ​

功能命令 / 快捷键
打开文件:e filename
同时打开多个文件vim file1 file2 ...
切换到下一个文件:n
切换到上一个文件:N
查看已打开文件列表:ls 或 :buffers
切换到指定 buffer:bN（N 为编号）
删除 buffer（不关闭窗口）:bd

分屏（Split） ​

功能快捷键
水平分屏:sp filename 或 Ctrl + w s
垂直分屏:vsp filename 或 Ctrl + w v
在分屏间切换Ctrl + w h/j/k/l
调整分屏大小（增加高度）Ctrl + w +
调整分屏大小（减少高度）Ctrl + w -
调整分屏宽度（增加）Ctrl + w >
调整分屏宽度（减少）Ctrl + w <
平均分配所有分屏Ctrl + w =
关闭当前分屏:q 或 Ctrl + w c
关闭除当前分屏外所有分屏:only 或 Ctrl + w o

🗂️ Tab 管理 ​

功能命令 / 快捷键
新建一个 tab:tabnew
打开文件在新 tab:tabedit filename
从 buffer 打开新 tab:tab split
关闭当前 tab:tabclose
关闭所有 tab（退出）:tabonly
切换到下一个 tab:tabn 或 gt
切换到上一个 tab:tabp 或 gT
跳转到第 N 个 tabNgt（例如 2gt）
查看 tab 列表:tabs

🔄 窗口 & NERDTree 结合操作 ​

  • 在 NERDTree 中选择文件：
    • t → 在新 tab 打开
    • i → 在水平分屏打开
    • s → 在垂直分屏打开
  • 利用 Ctrl + w 系列命令在 NERDTree 和编辑窗口之间切换。

💡 常用组合技巧 ​

  • 快速在多个文件间切换
    使用 :ls 查看 buffer → :bN 切换
    配合 NERDTree 直接定位文件更快。

  • 多任务编辑推荐

    • 同一项目不同文件：用 分屏（split）
    • 不同项目文件：用 Tab
    • 目录/文件树管理：用 NERDTree

📌 建议：可以在 .vimrc 里增加一些快捷键绑定，比如：

vim
" 快捷键：<leader>n 打开/关闭 NERDTree
nnoremap <leader>n :NERDTreeToggle<CR>

" 快捷键：<leader>f 定位到当前文件
nnoremap <leader>f :NERDTreeFind<CR>
